# 📚 Librería & Papelería — Consulta y Gestión de Precios

Aplicación web ultra rápida y ligera desarrollada con **Vite**, **React**, **Tailwind CSS** y **Supabase**, optimizada para despliegue instantáneo en **Vercel**. Diseñada para consulta rápida en mostrador y administración ágil de precios con PIN de seguridad.

---

## 🚀 Características Principales

1. **Modo Consulta (Personal de Mostrador):**
   - ⚡ **Búsqueda instantánea en tiempo real:** Filtra por nombre mientras escribes.
   - 🏷️ **Filtros por categoría:** Botones tipo chip (*Cuadernos*, *Bolígrafos*, *Papelería*, *Marcadores*, etc.).
   - 🇧🇴 **Precios en Bolivianos:** Formato destacado (`Bs. 15.50`).
   - 🔀 **Vistas alternables:** Tabla compacta de alta densidad para mostrador o tarjetas visuales.
   - ⌛ **Estados de carga elegantes:** Skeleton loader y mensajes cuando no hay coincidencias.

2. **Modo Encargado (Administración con PIN):**
   - 🔒 **Acceso protegido por PIN:** Modal con PIN por defecto `1234`.
   - ✏️ **Edición rápida de precios:** Edita cualquier precio directamente con 1 clic sin salir de la lista.
   - ➕ **Nuevo Producto:** Modal para dar de alta productos con nombre, categoría y precio.
   - 👁️ **Activar / Desactivar:** Oculta productos agotados sin necesidad de borrarlos.
   - 🗑️ **Eliminación con confirmación:** Elimina ítems que ya no se comercializan.
   - 🔔 **Feedback visual (Toasts):** Alertas rápidas de confirmación y error.

## ⚡ Guía Rápida de Uso

### 1. Configurar Supabase
Abre el archivo `.env` y coloca tu **Anon / Publishable Key** de Supabase:
```env
VITE_SUPABASE_URL=https://gpzsgcosjkkrzxheubqd.supabase.co
VITE_SUPABASE_ANON_KEY=TU_SUPABASE_ANON_KEY_REAL
```

*(Si la tabla `productos` no tiene datos o si la creas de cero, abajo tienes el script SQL).*

### 2. Ejecutar en Local
```bash
npm install
npm run dev
```
La aplicación abrirá en `http://localhost:3000`.

### 3. Compilar para Producción
```bash
npm run build
```
Genera la carpeta optimizada `dist/`.

## 🗄️ Esquema SQL de Supabase (Referencia)

```sql
create table if not exists productos (
  id bigint generated by default as identity primary key,
  nombre text not null,
  categoria text not null default 'Papelería',
  precio numeric(10,2) not null default 0.00,
  activo boolean not null default true,
  created_at timestamptz default now()
);

-- Políticas RLS (Row Level Security) para acceso directo anónimo:
alter table productos enable row level security;

create policy "Permitir lectura publica"
on productos for select
using (true);

create policy "Permitir insercion"
on productos for insert
with check (true);

create policy "Permitir actualizacion"
on productos for update
using (true);

create policy "Permitir eliminacion"
on productos for delete
using (true);
```
